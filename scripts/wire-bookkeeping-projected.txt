# wire-bookkeeping-projected.txt — every persisted record whose bookkeeping fields are
# declared but cannot reach a response body, because the service renders its responses
# from a separate wire struct.
#
# Columns, tab-separated:  file  struct-type  Test-that-proves-it
#
# THIS FILE IS THE OPPOSITE OF THE BASELINE. Every line in
# scripts/wire-bookkeeping-baseline.txt is a defect owed a fix; every line here is a site
# that should stay, so it has to argue for itself — the posture of
# check-discarded-unmarshal.sh's ALLOWED_FILES rather than the baseline's. The argument is
# the third column: a named test asserting on the raw bytes of every response that answers
# the record that no unpublished member appears in them.
#
# Why the two files, and not one. The baseline is the *declaration* surface — the set of
# bookkeeping fields carrying a wire-visible json tag — and it is regenerated by awk from
# the tree (`--write`), so nothing hand-written survives in it. That number is the upper
# bound on the leak and it barely moves, because the fix does not remove the field:
# emulator/ecr_wire.go says why in as many words — `json:"-"` and retyping in place both
# change the format of every recorded run, since MemoryStateManager snapshots those bytes
# and a replay reads them back. So a fixed service keeps its baseline lines and earns a
# line here, and the number #756's AC3 drives to zero is the difference between the two.
#
# A line here is refused unless the named type has at least one line in the baseline (a
# projection for a record with no bookkeeping field is a stale claim) and the named test is
# defined in emulator/. Renaming or deleting the test fails the check, which is what keeps
# the third column a citation rather than a comment.
#
# Adding a line: write the wire struct and the projection (emulator/ecr_wire.go is the
# pattern, emulator/iam_shape_members_test.go:115 the template for the assertion), then add
# the record here in the same commit.
